# 데이터 정책

이 문서는 JPA 구조만으로 알 수 없는 장기 유지 정책만 기록합니다. 테이블명, 컬럼명, 타입, 인덱스 목록은 엔티티를 기준으로 확인합니다.

## 공통

- 상태와 이력이 필요한 데이터는 물리 삭제보다 비활성·만료 상태를 우선합니다.
- 시간 기반 만료는 조회와 사용 시점에 판정하는 lazy expiration을 기본으로 하며, 별도 정리 배치는 운영 필요가 생길 때 도입합니다.
- enum은 순서가 아닌 문자열로 저장합니다.
- 개인정보, 인증 코드, 토큰은 로그에 남기지 않습니다.

## 회원과 약관

- 로컬 회원과 소셜 회원은 하나의 회원 모델을 사용합니다.
- 회원 탈퇴는 상태를 비활성으로 전환하는 soft deactivation을 기본으로 합니다.
- 필수 약관은 최신 이용약관과 개인정보 처리방침 버전을 기준으로 판정하며, 회원의 동의 이력은 보존합니다.
- 필수 약관 동의 완료 여부는 별도 플래그가 아니라 동의 이력과 현재 필수 버전으로 계산합니다.
- 회원별 취향 프로필은 하나이며, 속성·제한 재료·비선호 메뉴는 공용 마스터와의 매핑으로 관리합니다.
- 회원 위치는 선택 정보이며 추천에 자동 적용하지 않습니다.

## 인증

- 이메일 인증 코드와 검증 토큰은 원문 대신 hash를 저장하고 일회성으로 사용합니다.
- 동일한 이메일·목적의 재전송 이력을 보존하되, 새 인증 요청이 생성되면 기존 대기 요청은 만료합니다.
- 인증 교환 코드는 짧은 수명의 일회성 값이며 사용 시각을 기록합니다.
- refresh token은 서버 저장소에서 유효성을 통제합니다. 현재는 원문을 저장하며, hash 저장·재사용 탐지·기기 메타데이터는 별도 보안 개선 범위입니다.

## 메뉴와 이미지

- 추천의 기본 단위는 장소가 아니라 메뉴입니다.
- 속성 카테고리와 재료는 개인·그룹 추천에서 공유하는 마스터 데이터입니다.
- 마스터 데이터의 `code`는 안정적인 비즈니스 키로 취급하고, 사용 중단은 삭제보다 비활성으로 표현합니다.
- seed는 기존 마스터 데이터를 임의로 수정하거나 삭제하지 않습니다.
- 이미지 자산은 범용 메타데이터로 관리하고, 메뉴 대표 이미지와 회원 현재 프로필 이미지는 별도 연결로 표현합니다.
- 회원 프로필 이미지 변경 이력은 저장하지 않으며 회원별 현재 연결 한 건만 유지합니다.
- 삭제된 프로필 프리셋은 신규 선택에서 제외하되 기존 회원 연결과 이미지 자산은 보존합니다.
- 활성 기본 프로필 프리셋은 최대 한 개이며 현재 기본 프리셋은 다른 기본을 지정하기 전에 삭제할 수 없습니다.
- 업로드 이미지는 JPEG, PNG, WebP만 허용하며 크기는 5 MiB 이하, 해상도는 300×300 이상 4096×4096 이하로 제한합니다.
- 스토리지 객체 삭제 실패는 DB 트랜잭션을 되돌리지 않는 best-effort 정리로 취급합니다.

## 개인 추천

- 개인 추천 세션과 후보는 메뉴 선택 과정을 기록하며, 최종 선택 전 세션은 요청 후 24시간이 지나면 만료합니다.
- 추천 당시의 가변 context와 후보 설명 메타데이터는 JSON으로 보존할 수 있습니다.
- 회원의 메뉴 행동은 별도 이력으로 기록하고, `SKIP`은 일정 기간 후보에서 제외하는 신호로 사용할 수 있습니다.

## 그룹

- 그룹 방은 soft delete하며, 멤버의 퇴장 상태와 초대·참여 이력은 보존합니다.
- 방장도 그룹 멤버로 저장합니다.
- 그룹 위치는 변경 이력을 수용할 수 있게 관리하고, presence는 현재 상태가 아닌 이벤트 로그로 기록합니다.
- 초대 링크는 발급 이력을 보존하며 만료 시각으로 유효성을 판정합니다. 재발급하면 기존 링크를 즉시 만료합니다.
- 그룹 추천은 준비와 투표 상태를 가지며, 완료되지 않은 세션은 24시간 후 만료합니다.
- 한 회원은 추천 세션마다 하나의 투표를 가지며 재투표는 후보를 변경합니다.
- 그룹에서 발생한 행동은 개인 취향으로 자동 승격하지 않습니다.
- 최종 위치 snapshot은 위치가 제공된 경우에만 저장합니다.
